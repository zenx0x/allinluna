# All in Luna entry

Start with `$allinluna-plan` when you need a complete, dependency-aware development plan. Use `$allinluna-run` after approval, or use `parallel-only` when the plan already exists. All in Luna is the lean development-concurrency distribution: it coordinates a separate Coordinator, dependency-wave Owners, worktrees, recovery, and mechanical integration when needed, without creating a Goal or extra Acceptance/CounterPilot lanes.
